## 🚀 Summary

Finding a way to recycle one us plastic.  can be reused to manufacture into what ever you can imagine.

HDPE (Milk Bottles) and Pet (Coke Bottles) are the most easy to work with.
This wast plastic can be turn into re-mix and used to manufacture what ever you can imagine.

You need to
 - Clean it
 - Cut it up
 - Heat it
 - Shape it, normally via a mould

Re-Mix can be put in an Extruder and used with a mould to make objects or into open mould and make solid building products
like Beams, Angels, Rounds and many other things.

Extruded plastic beams can be used to make a picnic table and more

It can be worked and finished with wood working tools ie. Power tools like wood thickness planer lathe etc

## 📦 Plastic and A Toasted Sandwich Maker

The best and easiest entry point is to use a Toasted sandwich maker and a basic mould eg a pie dish
The plastic bottles should be cut into strips. Caps can be used as is.
Melt plastic in Toasted sandwich maker add plastic until you have require quantity of melted plastic
Remove and place in pre-setup mould, must move fast with good gloves
Clamp mould and wait
See BrothersMake for good examples on doing this

## 📦 ZoE - Shredder of Extruder, a Plastic Recycling machine
With a need for a shedder and an extruder and no budget i combined the two machines into one
A Morrison Electric garden shredder is used as the main motor
ZoE has slip jaw chuck allowing the Extruder screw to be disengaged as required
A RPi5 is used to provide Heater element(3) control via SSR(3), and a Thermocouple(3) feeding a PID loop (3 PID setups)
This set up allow granulation of plastic into regrind. Then melting and extruding
At the Extruder nozzle a closed mode can be attached or a open mold like a square tube, this produces a plastic beam
